# تصاویر راهنمای آشنا

این ۱۴ تصویر از یک نصب **واقعی وردپرس ۶.۸.۳ فارسی و راست‌به‌چپ** با PHP 8.3 و SQLite گرفته شده‌اند. نصب ZIP، فعال‌سازی از پیشخوان، تب‌های آشنا و خروجی شورت‌کد در مرورگر واقعی مشاهده شده‌اند. تصویرها برای خوانایی برش خورده‌اند؛ چیدمان و برچسب‌های رابط افزونه بازطراحی یا بازنویسی نشده‌اند.

محیط تصویربرداری **آزمایشی و جدا از بستهٔ توزیع** بوده است: فایل رسمی لایسنس جدید در دسترس نبود، بنابراین تنها در یک ZIP موقت داخل `.cache/help-fixture/` از لایسنس شبیه‌سازی‌شده استفاده شد تا پنل در سایت آزمایشی اجرا شود. هش‌های همان کپی آزمایشی با fixture هماهنگ شده‌اند؛ `deliverables/ashna.zip` و فایل رسمی لایسنس تغییر نکرده‌اند. این تصاویر اثبات فعال‌شدن لایسنس واقعی راست‌چین یا خروجی انکودر نیستند. در تصویر گوگل، دامنهٔ رزروشدهٔ `demo.example.com` نیز صرفاً نمونه است و باید در سایت واقعی، آدرس همان سایت کپی شود.

## بازسازی تصاویر در محیط آزمایشی

۱. یک سایت موقت و جداگانه با وردپرس فارسی (`fa_IR` و RTL)، مدیر آزمایشی و آشنا ۳.۱.۴ آماده کنید. برای تصویر فرم، یک برگهٔ عمومی شامل `[ashna_otp_login]` بسازید. این محیط و فایل‌های fixture را روی سایت واقعی، سرور عمومی یا داخل بستهٔ فروش قرار ندهید.

۲. برای نمایش نام دامنهٔ نمونه در تصویر گوگل، فایل `tests/browser/ashna-help-sample-domain.php` را فقط در پوشهٔ `wp-content/mu-plugins/` همان سایت موقت کپی کنید. این فیلتر صرفاً آدرس نمایشی بازگشت گوگل/تلگرام را تغییر می‌دهد و برای سایت واقعی مناسب نیست.

۳. وابستگی‌های محلی را نصب کنید، سایت آزمایشی را محلی اجرا کنید و اسکریپت را با نام کاربری و رمز مدیر آزمایشی و مسیر برگه اجرا کنید. برای عکاسی مراحل نصب، آشنا نباید قبلاً در آن سایت نصب شده باشد و ZIP آزمایشی باید در `.cache/help-fixture/ashna.zip` قرار داشته باشد. اسکریپت فقط آدرس `127.0.0.1` را می‌پذیرد و اگر افزونه از قبل نصب باشد، مرحلهٔ نصب را رد می‌کند؛ برای بازسازی فقط تصاویر تنظیمات در سایت آماده، `HELP_CAPTURE_INSTALL=0` را اضافه کنید.

```sh
npm install --prefix .cache playwright-core@1.54.2 @sparticuz/chromium@131.0.1 sharp
HELP_WP_USER='نام-مدیر-آزمایشی' HELP_WP_PASSWORD='رمز-آزمایشی' \
  HELP_LOGIN_PAGE='/?page_id=7' node scripts/capture-help-screens.mjs
```

در برخی محیط‌های لینوکس حداقلی، Chromium به کتابخانه‌های مشترک اضافی نیاز دارد؛ پس از آماده‌سازی آن‌ها، `LD_LIBRARY_PATH` را به مسیر کتابخانه‌ها تنظیم کنید. از گذرواژه، لایسنس، شماره موبایل یا کلید واقعی در fixture استفاده نکنید.

## بازسازی PDF

```sh
node scripts/render-help-pdf.mjs
```

اسکریپت، فونت محلی، ۱۴ تصویر، دادهٔ جایگزین تصاویر، وضعیت صفحه‌بندی و سرریز را بررسی می‌کند و در صورت خطا PDF را منتشر نمی‌کند. پس از بازسازی، صفحه‌های PDF را از نظر خوانایی بازبینی و اندازه و SHA-256 آن را در `deliverables/checksums.json` به‌روزرسانی کنید.
