تاریخچه تغییرات آشنا
آخرین نسخه: ۳.۱.۳

نسخهٔ ۳.۱.۳
- ورود با گوگل و تلگرام (OIDC + PKCE) با آدرس بازگشتی اختصاصی هر سرویس، بررسی امضا/nonce و قاعدهٔ اتصال امن حساب.
- زنجیرهٔ ۳ درگاه پشتیبان با Circuit Breaker، سقف زمانی کل و بررسی خودکار سلامت هر ۵ دقیقه.
- ضد پیامک‌بمب: سقف دقیقه‌ای/ساعتی/روزانه برای شماره، IP و شبکه، رزرو اتمیک سهمیه و حالت حمله.
- استودیوی طراحی زنده با ۴ قالب آماده، انتخاب رنگ، CSS سفارشی و دارک‌مود.
- یکپارچگی ووکامرس (کلاسیک، بلوکی و HPOS)، دکان، Ultimate Member، PMPro و MemberPress.
- پایداری: مسیر بازگشت به ورود کلاسیک، منطقهٔ زمانی مستقل و پیام خطای فارسی برای خطاهای ارسال.
- هویت بصری و متن‌ها با نام آشنا یکدست شد؛ فونت‌های وزیرمتن و استعداد داخل افزونه و بدون CDN.

پیش‌نیازها
- وردپرس ۵.۸ یا بالاتر؛ PHP ۸.۲ یا بالاتر برای نسخهٔ لایسنس‌دار؛ ionCube Loader روی همان PHP وب.
- برای Passkey و ورود گوگل/تلگرام، HTTPS الزامی است.
