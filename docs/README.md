# راهنمای فارسی قابل بازسازی

- `guide-fa.html`: منبع چهارصفحه‌ای راهنمای PDF؛ راست‌به‌چپ با فونت‌های محلی Estedad و لوگوی تأییدشده.
- `changelog-FA.txt`: تاریخچهٔ داخل بستهٔ راست‌چین.
- خروجی اصلی: `deliverables/Signa-Help-FA.pdf`.
- بستهٔ گردآوری‌شده: `rightchin/Signa-Rightchin-Package.zip`؛ فایل نصب داخلی عیناً آخرین `deliverables/signa-otp-with-logo.zip` است.

بازسازی از ریشهٔ مخزن:

```sh
npm ci --prefix product-images/gallery-design
SIGNA_BUNDLED_LIBS=1 node scripts/render-help.mjs
python scripts/package-rightchin.py
```

در محیط دارای Chromium نصب‌شده می‌توان `CHROME_PATH` را تعیین کرد. منابع HTML، لوگو و فونت با file URL محلی بارگذاری می‌شوند و PDF به منابع خارجی وابسته نیست. وابستگی‌های Node و فایل اجرایی مرورگر داخل Git یا ZIP نهایی قرار نمی‌گیرند.

رندر قبل از خروجی‌گرفتن، لود فونت و تصویر، شمار چهار صفحهٔ HTML، سرریز افقی و فاصلهٔ محتوا از پاورقی را بررسی می‌کند. برای کنترل نهایی، تعداد صفحات و نمایش PDF نیز بررسی شوند.

اسکریپت بسته‌بندی، CRC و برابری بایتی PDF و ZIP داخلی با خروجی‌های فعلی را بررسی و checksumها را ثبت می‌کند. این بازسازی، ZIP نصب یا لایسنس را تغییر نمی‌دهد. اگر کد افزونه عوض شد، ابتدا بستهٔ نصب را با اسکریپت اصلی بازسازی کنید.

**محدودیت انتشار:** راهنما و بستهٔ فعلی صریحاً نبود فایل واقعی لایسنس را اعلام می‌کنند. پیش از افزودن لایسنس معتبر و انتشار نهایی، این توضیحات و checksum فایل نصب باید با محتویات واقعی هماهنگ شوند. آزمون‌های رندر یا checksum، تأیید اجرای لایسنس یا سلامت سایت مشتری نیستند.
