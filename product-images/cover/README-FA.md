# کاور محصول آشنا — راهنمای ویرایش و خروجی

ابعاد: **۲۱۰۰×۱۰۴۰** (دو برابر ۱۰۵۰×۵۲۰ نمایشی راست‌چین)
نسخهٔ موبایل: **۱۲۰۰×۱۲۰۰** (فایل جدا)

## ساختار طرح

چیدمان دو ستونه؛ سمت راست هویت و متن، سمت چپ تصویرسازی:

| ناحیه | محتوا |
|---|---|
| نوار بالای راست | پیل «افزونهٔ وردپرس» و پیل «محصول ایرانی» با پرچم |
| برند | لوگوی سفید `ashna-logo-white.svg`، بزرگ و سه‌بعدی: ماسک SVG + سطح فلزی + اکستروژن + سایهٔ بلند |
| زیرعنوان | «ورود و ثبت‌نام پیامکی وردپرس» + پیل «بدون رمز عبور» |
| نام انگلیسی | `ASHNA — OTP LOGIN WORDPRESS PLUGIN` |
| پنج ویژگی | دقیقاً همان پنج خط متن معرفی، با آیکون SVG دست‌ساز |
| پایین راست | «محصولی از پارسنا · parsena.ir/ashna» |
| چپ | گوشی با فرم کد تأیید + نوتیف پیامک + کارت سقف ضد اسپم + کارت درگاه‌ها |
| پایین چپ | نوار اعتماد: آمادهٔ نصب · بدون رمز عبور · ورود بیومتریک · ضد اسپم و بمبر |

نکته: کارت ضد اسپم اعداد پیش‌فرض واقعی افزونه را نشان می‌دهد
(۵ در دقیقه برای هر IP، ۱۰ در ۲۴ ساعت برای هر شماره، فاصلهٔ ارسال دوباره ۶۰ ثانیه)
تا هیچ ادعای تست‌نشده‌ای روی کاور نیاید.

## لایه‌های نشان سه‌بعدی

نشان دیگر یک `<img>` تخت نیست؛ یک استک از همان لوگو با ماسک SVG است (در `mobile.html` هم تکرار شده):

| لایه | نقش |
|---|---|
| `.w-pool` | نور کف زیر حروف |
| `.w-glow` | هالهٔ آبی محیطی |
| `.w-shadow` / `.w-shadow2` | سایهٔ بلند نرم و سایهٔ تماس |
| `.w-depth-1..3` | اکستروژن سه‌پله در سرمه‌ای تدریجی |
| `.w-face` | سطح فلزی: تاج سفید تا پای آبی یخی |
| `.w-shade` / `.w-bounce` | سایهٔ داخلی و نور بازتاب کف |
| `.w-gloss` / `.w-rim` | برق سطح و ریم‌لایت لبه |

برای تغییر اندازه فقط `width/height` والد `.wordmark` را عوض کن؛ نسبت لوگو ۸۲۰:۲۴۰ است.
`check.mjs` عمداً استک نشان را از بررسی بیرون‌زدگی کنار می‌گذارد، چون لایه‌های سایه باید از کادر بیرون بزنند.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | کاور دسکتاپ، قابل ویرایش، همه‌چیز inline |
| `mobile.html` | کاور موبایل، چیدمان عمودی جداگانه |
| `ashna-cover.jpg` | خروجی نهایی دسکتاپ — ۲۱۰۰×۱۰۴۰ — حدود ۲۶۰ کیلوبایت |
| `ashna-cover-mobile.jpg` | خروجی نهایی موبایل — ۱۲۰۰×۱۲۰۰ |
| `render.mjs` | خروجی PNG در مقیاس ۱ و ۲ |
| `mobile.mjs` | خروجی PNG نسخهٔ موبایل |
| `check.mjs` | بررسی بیرون‌زدگی و سرریز متن پیش از خروجی |
| `img/security-quota.webp` | برش واقعی پنل امنیت (استفادهٔ اختیاری) |

فونت‌ها و لوگوها از مسیرهای نسبی خوانده می‌شوند: `../../assets/fonts/…` و `../infographic/img/…`.

## چرخهٔ ویرایش

```sh
# پیش‌نمایش (از ریشهٔ مخزن)
python3 -m http.server 8124 --bind 0.0.0.0 --directory .
# سپس: http://127.0.0.1:8124/product-images/cover/index.html

# کنترل بیرون‌زدگی (باید "out": [] برگرداند)
LD_LIBRARY_PATH=/tmp/alx/lib node product-images/cover/check.mjs

# خروجی PNG در مقیاس ۱ (کافی برای JPG نهایی) و ۲ (مستر رتینا)
cd product-images/cover
LD_LIBRARY_PATH=/tmp/alx/lib node render.mjs 1 /tmp/cover-1x.png
LD_LIBRARY_PATH=/tmp/alx/lib node render.mjs 2 /tmp/cover-2x.png

# تبدیل به JPG نهایی
python3 -c "from PIL import Image; Image.open('/tmp/cover-1x.png').convert('RGB').save('ashna-cover.jpg', quality=92, optimize=True, progressive=True, subsampling=1)"
```

## قواعد ثابت

- هیچ تصویر آماده، استوک یا هوش مصنوعی در کاور نیست؛ همهٔ آیکون‌ها و وکتورها SVG دست‌سازند.
- لوگو از فایل رسمی خود محصول خوانده می‌شود، نه بازکشیده‌شده.
- پرچم ایران واترمارک نیست؛ نشان «محصول ایرانی» است و داخل یک پیل قرار دارد.
- متن‌ها باید با متن معرفی محصول یکی باشند؛ اگر متن عوض شد، هر دو فایل به‌روز شوند.
