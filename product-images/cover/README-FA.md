# کاور محصول آشنا — راهنمای ویرایش و خروجی

ابعاد: **۲۱۰۰×۱۰۴۰** (دو برابر ۱۰۵۰×۵۲۰ نمایشی راست‌چین)
نسخهٔ موبایل: **۱۲۰۰×۱۲۰۰**

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | کاور دسکتاپ، قابل ویرایش، همه‌چیز inline |
| `mobile.html` | کاور موبایل، چیدمان عمودی جداگانه |
| `ashna-cover.jpg` | خروجی نهایی دسکتاپ — ۲۱۰۰×۱۰۴۰ — حدود ۳۰۰ کیلوبایت |
| `ashna-cover-mobile.jpg` | خروجی نهایی موبایل — ۱۲۰۰×۱۲۰۰ — حدود ۲۱۰ کیلوبایت |
| `render.mjs` | خروجی PNG در مقیاس ۱ و ۲ |
| `mobile.mjs` | خروجی PNG نسخهٔ موبایل |
| `check.mjs` | بررسی هم‌پوشانی بلوک‌ها پیش از خروجی |
| `shot.mjs` | اسکرین‌شات سریع یک‌باره |

فونت‌ها و آیکون‌ها از مسیرهای نسبی خوانده می‌شوند: `../../assets/fonts/…` و `../infographic/img/…`.

## چرخهٔ ویرایش

```sh
# پیش‌نمایش
python3 -m http.server 8124 --bind 0.0.0.0

# کنترل هم‌پوشانی (باید [] برگرداند)
LD_LIBRARY_PATH=/tmp/alx/lib node check.mjs

# خروجی PNG در مقیاس ۱ و ۲
LD_LIBRARY_PATH=/tmp/alx/lib node render.mjs 1 /tmp/cover-1x.png
LD_LIBRARY_PATH=/tmp/alx/lib node render.mjs 2 /tmp/cover-2x.png

# خروجی JPEG
python3 -c "from PIL import Image; Image.open('/tmp/cover-1x.png').convert('RGB').save('ashna-cover.jpg','JPEG',quality=90,optimize=True,progressive=True,subsampling=0)"
```

برای نسخهٔ موبایل، همین دستورها با `mobile.mjs` و `ashna-cover-mobile.jpg`.

## ساختار طرح

**ستون راست (هویت):** نشان «آشنا» از `ashna-logo-white.svg` → نوار آبی زیرعنوان → نام انگلیسی `ASHNA — OTP LOGIN WORDPRESS PLUGIN` → پنج ویژگی اصلی، با واژه‌های کلیدی پررنگ.

**ستون چپ (وکتور):** گوشی با صفحهٔ واقعی ورود آشنا (کد ۶ رقمی، دکمهٔ «دریافت کد تأیید»، ورود گوگل و تلگرام) + سه کارت شیشه‌ای: پیامک کد تأیید، ضد اسپم و بمبر، ورود با تلگرام + شبکهٔ شش درگاه پیامکی.

**پس‌زمینه:** سرمه‌ای آشنا با شبکهٔ نقطه‌ای، کمان‌های محو و دو هالهٔ آبی. نوار نور در لبهٔ بالا.

## قواعد ثابت

- هیچ تصویر آماده، استوک یا تولیدشده با هوش مصنوعی استفاده نشده؛ همهٔ گرافیک SVG یا CSS است.
- پنج ویژگی کاور کلمه‌به‌کلمه همان پنج ویژگی متن معرفی است.
- عنوان «آشنا»، زیرعنوان کوتاه، نام انگلیسی، نشان ایران، پنج ویژگی و وکتور مرتبط — همه سر جای خودشان هستند.
- رنگ متن‌ها با پس‌زمینه هم‌خوان است و برای خوانایی در اندازهٔ کوچک هم تست شده.

## اگر عنوانی را عوض کردی

متن‌ها همه در `index.html` و `mobile.html` هستند؛ برای تغییر زیرعنوان فقط `.subbar b` را عوض کن و اگر طولش زیاد شد `font-size` را ۲ تا ۴ پیکسل کم کن. بعد `check.mjs` را اجرا کن تا هم‌پوشانی جدید پیدا شود.
