# کاور محصول آشنا — راهنمای ویرایش و خروجی

ابعاد: **۲۱۰۰×۱۰۴۰** (جی‌پی‌جی، RGB، حدود ۲۵۰ کیلوبایت)
نسخهٔ موبایل: **۱۲۰۰×۱۲۰۰** (فایل جدا)

طرح بر پایهٔ استانداردهای کاور و آیکون RTL-Theme بازنویسی شده است:
پس‌زمینهٔ رنگ اصلی محصول (نه سفید)، ماکاپ دستگاه مدرن با اسکرین‌شات واقعی محصول،
تیتر درشت و خوانا، حاشیهٔ امن، و یک پترن در پس‌زمینه.

## محتوای کاور — فقط سه چیز

به درخواست کارفرما، کاور فقط این سه بلوک را دارد و هیچ چیز دیگری روی آن نیست
(نه پیل، نه نوار اعتماد، نه نام انگلیسی، نه آدرس سایت، نه فوتر، نه امضا):

| بلوک | محتوا |
|---|---|
| عنوان | لوگوتایپ رسمی «آشنا» (فایل `img/ashna-logo-crop.svg`)، بزرگ و سه‌بعدی |
| زیرعنوان | «ورود و ثبت‌نام پیامکی وردپرس» — یک عبارت چندکلمه‌ای |
| ویژگی‌ها | چهار خط کوتاه، هر خط با یک آیکون سه‌بعدی اختصاصی |

**قاعدهٔ هم‌ترازی:** لبهٔ راست عنوان، زیرعنوان و ستون آیکون ویژگی‌ها روی یک محور است.
در `index.html` این محور `right: 100px` روی `2100px` است، یعنی `x = 2000`.
اگر اندازهٔ لوگو یا حاشیه عوض شد، هر سه بلوک باید همان لبه را نگه دارند
(لوگو به‌خاطر برش دقیق `ashna-logo-crop.svg` هیچ حاشیهٔ خالی داخلی ندارد).

**سازگاری محصولات روی کاور نمی‌آید.** خط «ورود و ثبت‌نام در ووکامرس، دکان، المنتور…»
عمداً حذف شده است؛ اگر روزی محتوا عوض شد، این قاعده پابرجاست.

## ساختار طرح دسکتاپ

| ناحیه | محتوا |
|---|---|
| راست | عنوان (لوگو) ← زیرعنوان ← خط جداکننده ← چهار ویژگی، همه راست‌چین روی یک محور |
| چپ | پنجرهٔ دستگاه با اسکرین‌شات واقعی محصول: `../infographic/img/login-card.webp` |
| پس‌زمینه | گرادیان سرمه‌ای برند + پترن سپر `img/pattern-shield.svg` + حلقه‌های نرم + دانهٔ ریز |

اسکرین‌شات داخل پنجره، تصویر واقعی صفحهٔ ورود افزونه است؛ هیچ بخشی از پنل بازکشیده نشده.
نوار بالای پنجره (سه نقطه + پیل «آشنا») فقط قاب ماکاپ است، نه صفحهٔ محصول.

## ویژگی‌ها و آیکون‌های سه‌بعدی

| # | متن | آیکون | کلاس |
|---|---|---|---|
| ۱ | ورود با **کد پیامکی**، بدون رمز عبور | حباب پیام با سه نقطه | `.fico.f1` |
| ۲ | پشتیبانی از **شش درگاه پیامکی** ایرانی | سه لایهٔ روی‌هم | `.fico.f2` |
| ۳ | **ضد اسپم و بمبر** با سقف دقیقه‌ای | سپر با تیک | `.fico.f3` |
| ۴ | ورود با **گوگل، تلگرام و Passkey** | کلید | `.fico.f4` |

آیکون‌ها SVG دست‌ساز روی کاشی‌های «خمیری» سه‌بعدی‌اند: گرادیان دو رنگ + هایلایت بالایی +
اکستروژن `box-shadow` + سایهٔ نرم + براقی `::after`. رنگ هر کاشی با متغیرهای
`--top`، `--bot` و `--deep` همان کلاس عوض می‌شود.

## لایه‌های نشان سه‌بعدی

نشان یک `<img>` تخت نیست؛ استکی از همان لوگو با ماسک SVG است:

| لایه | نقش |
|---|---|
| `.w-glow` | هالهٔ آبی محیطی پشت حروف |
| `.w-shadow` / `.w-shadow2` | سایهٔ تماس نرم و سایهٔ بلند محیطی |
| `.w-face` | سطح سفید با پای آبی یخی |
| `.w-shade` / `.w-bounce` | سایهٔ داخلی و نور بازتاب کف |
| `.w-gloss` / `.w-rim` | برق سطح و ریم‌لایت لبه |

اگر اکستروژن سه‌بعدی خواستی، دو لایهٔ `.w-depth-1/2` را دوباره اضافه کن
(در نسخهٔ فعلی عمداً حذف شده‌اند تا حروف در سایز کوچک تمیز بمانند).
برای تغییر اندازه فقط `width/height` والد `.wordmark` را عوض کن؛ نسبت برش لوگو
`703.3117 : 215.1724` (تقریباً `3.2687`) است، پس ارتفاع = عرض ÷ ۳٫۲۶۸۷.
`check.mjs` استک نشان و لایه‌های پس‌زمینه را (با `[data-bleed]`) از بررسی بیرون‌زدگی کنار می‌گذارد.

## ساختار نسخهٔ موبایل (۱۲۰۰×۱۲۰۰)

همان زبان بصری، چیدمان مربعی: راست = عنوان، زیرعنوان و چهار ویژگی با همان محور
(`right: 54px`)؛ چپ = تبلت با اسکرین‌شات واقعی `../infographic/img/00-card.webp`.
پترن، حلقه‌ها، درخشش و سایهٔ کف مثل نسخهٔ دسکتاپ تکرار شده‌اند.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | کاور دسکتاپ، همه‌چیز inline |
| `mobile.html` | کاور موبایل، چیدمان جداگانه |
| `img/ashna-logo-crop.svg` | لوگوی رسمی سفید با viewBox برش‌خورده تا لبهٔ جوهر — پایهٔ هم‌ترازی عنوان |
| `img/pattern-shield.svg` | کاشی پترن پس‌زمینه (۳۶۰×۳۶۰، سپر محصول) |
| `img/security-quota.webp` | برش واقعی پنل امنیت (استفادهٔ اختیاری) |
| `ashna-cover.jpg` | خروجی نهایی دسکتاپ — ۲۱۰۰×۱۰۴۰ |
| `ashna-cover-mobile.jpg` | خروجی نهایی موبایل — ۱۲۰۰×۱۲۰۰ |
| `render.mjs` | خروجی PNG در مقیاس ۱ و ۲ |
| `mobile.mjs` | خروجی PNG نسخهٔ موبایل |
| `check.mjs` | بررسی بیرون‌زدگی و سرریز متن پیش از خروجی |

فونت‌ها و تصاویر از مسیرهای نسبی خوانده می‌شوند: `../../assets/fonts/…`،
`../infographic/img/…` و `../gallery-v2/…`. فونت‌ها Estedad (۴۰۰/۵۰۰/۷۰۰/۹۰۰) هستند؛
فونت‌های تجاری در مخزن نیستند و استفاده نشده‌اند.

## قواعد ثابت

- محتوای کاور فقط عنوان، زیرعنوان و ویژگی‌هاست؛ هیچ متن یا نشان اضافه‌ای اضافه نشود.
- سازگاری محصولات (ووکامرس/دکان/المنتور/افزونه‌های عضویت) در ویژگی‌ها نمی‌آید.
- عنوان، زیرعنوان و ویژگی‌ها همیشه روی یک محور راست هم‌تراز می‌مانند.
- پس‌زمینه باید پترن داشته باشد و رنگ اصلی محصول باشد، نه سفید یکدست.
- تصویر محصول باید اسکرین‌شات واقعی باشد (فایل‌های `infographic/` یا `gallery-v2/`)، نه شبیه‌سازی.
- آیکون‌ها SVG دست‌سازند؛ تصویر استوک یا هوش مصنوعی استفاده نمی‌شود.
- لوگو از فایل رسمی خود محصول خوانده می‌شود، نه بازکشیده‌شده.
- هیچ قیمت، تخفیف، «رایگان» یا لوگوی برند دیگر روی کاور نمی‌آید.
- متن‌ها باید با متن معرفی محصول یکی باشند؛ اگر متن عوض شد، هر دو فایل به‌روز شوند.
