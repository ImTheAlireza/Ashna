# گالری آشنا — HTML / CSS

این نسخه جایگزین تصاویر گالری تولیدشده با مدل تصویر شده است. تمام متن‌ها متن واقعی HTML هستند؛ تصویرسازی‌ها با CSS و SVG ساخته شده‌اند و نشان برند از فایل تأییدشده بارگذاری می‌شود.

## ساختار

- `index.html`: نمایش هر هشت خروجی و لینک طرح‌های زنده و دانلودها.
- `render.html?slide=1` تا `slide=8`: بوم مستقل هر طرح.
- `slides.js`: عنوان‌ها، توضیح‌ها و تصویرسازی‌های هشت ویژگی.
- `styles.css`: سیستم مشترک تایپوگرافی، رنگ، فاصله‌گذاری و چیدمان.
- `export.mjs`: اسکرین‌شات Chromium از بوم ۸۰۰ × ۹۰۰ با DPR=2؛ خروجی واقعی ۱۶۰۰ × ۱۸۰۰ بدون بزرگ‌نمایی تصویر رستری.
- `package_images.py`: تبدیل اسکرین‌شات‌ها به WebP، بررسی ابعاد و سقف حجم، ساخت ZIP.
- `../gallery/manifest.json`: گزارش مشخصات واقعی فونت و جایگاه عنوان‌ها و حجم فایل‌ها.

فونت استعداد (وزن‌های ۴۰۰، ۵۰۰، ۷۰۰ و ۹۰۰) از `assets/fonts/estedad` و لوگوها از `assets/images` بارگذاری می‌شوند. هیچ فونت یا کتابخانهٔ مرورگری به CDN وابسته نیست. رابط‌ها تصویرسازی معرفی قابلیت‌ها هستند، نه اسکرین‌شات پنل زندهٔ وردپرس. اعداد نمودار با برچسب «دادهٔ نمایشی» مشخص شده‌اند.

## پیش‌نمایش

از ریشهٔ مخزن:

```sh
python product-images/gallery-design/server.py --port 8000
```

سرور روی `0.0.0.0:8000` اجرا می‌شود. آدرس `/` به گالری هدایت می‌شود؛ لینک‌ها نسبی هستند.

## بازسازی خروجی‌ها

Node.js 22.17+ و Python 3.9+ توصیه می‌شود. در یک ترمینال سرور بالا را فعال نگه دارید. سپس از ریشهٔ مخزن:

```sh
npm install --prefix product-images/gallery-design
node product-images/gallery-design/export.mjs
python -m venv .venv
.venv/bin/pip install Pillow
.venv/bin/python product-images/gallery-design/package_images.py
```

برای محیط‌های حداقلی لینوکس بدون کتابخانه‌های NSS/NSPR، اجرا با `ASHNA_BUNDLED_LIBS=1` از کتابخانه‌های همراه بستهٔ Chromium استفاده می‌کند. `CHROME_PATH` مسیر مرورگر موجود و `ASHNA_GALLERY_URL` آدرس سرور جایگزین را تعیین می‌کنند. `ASHNA_RENDER_MODULES` فقط برای نصب ابزارها در یک مسیر خارجی اختیاری است.

خروجی‌های موقت PNG در `.cache/gallery-render/` و خروجی‌های نهایی WebP در `product-images/gallery/` قرار می‌گیرند. ZIP نهایی `product-images/ashna-gallery-8-images.zip` شامل دقیقاً هشت تصویر است.

## کنترل کیفیت خودکار

- انتظار برای بارگذاری و decode همهٔ تصاویر و بارگذاری فونت‌ها پیش از اسکرین‌شات.
- بررسی یکسان‌بودن فونت، اندازه، وزن، ارتفاع خط، مختصات و ابعاد تمام عنوان‌ها.
- بررسی نبود بریدگی عنوان، اسکرول بوم، خطای JavaScript یا پاسخ HTTP ناموفق.
- بررسی ابعاد دقیق ۱۶۰۰ × ۱۸۰۰ و حجم کمتر از ۱٬۰۰۰٬۰۰۰ بایت برای تک‌تک فایل‌ها.
- بررسی سلامت ZIP و وجود دقیقاً هشت تصویر در آن.

## بازطراحی تصاویر ۲، ۳ و ۵

- ۲: صفحهٔ اثر انگشت و پنجرهٔ تأیید هویت با Passkey؛ تیتر مشترک حفظ شده است.
- ۳: نمایش سه مسیر پیامک، بله و ایمیل در کنار موبایل دریافت‌کننده.
- ۵: `05-gateways.webp` جایگزین تصویر شخصی‌سازی ظاهر شده است؛ پنج پنل پیامکی، بله و ایمیل دور نشان آشنا قرار دارند.
- فایل‌های نشان‌ها محلی هستند؛ منابع و محدودیت نشان IPPanel در `logos/SOURCES.md` ثبت شده‌اند.
- در تغییر هویت به آشنا، هر هشت خروجی با نام و نماد نهایی دوباره رندر شده‌اند.
