| فایل | موضوع | حجم |
|---|---|---|
| `01-otp.webp` | ورود و ثبت‌نام با کد یکبارمصرف | ۱۰۴ KB |
| `02-gateways.webp` | شش درگاه پیامک، بله و ایمیل | ۱۰۵ KB |
| `03-limits.webp` | سقف درخواست، شمارش ارسال دوباره، کپچا و فهرست مسدود | ۱۰۹ KB |
| `04-failover.webp` | زنجیرهٔ درگاه اصلی و پشتیبان | ۱۰۹ KB |

جمع: ۸۵۹,۵۶۸ بایت.

## ساختار مشترک هر قاب

- بوم `800×900` در CSS که با `deviceScaleFactor: 2` رندر می‌شود؛ خروجی `1600×1800`.
- حاشیهٔ چپ و راست ۵۴، بالا ۵۲.
- شمارهٔ قاب در قرص آبی بالا-راست، نشان سپر در بالا-چپ، نوار پایین «آشنا · افزونهٔ وردپرس» و «قاب ۰N از ۰۸».
- زیر هر توضیح، یک خط کوتاه گرادیانی آبی با گرهٔ روشن؛ همان امضای تصویری در هر هشت قاب تکرار می‌شود تا مجموعه یک‌دست دیده شود.
- عنوان دو خطی، Estedad 900، ۵۰ پیکسل. خط دوم با رنگ آبی برند.
- رنگ‌ها: سرمه‌ای `#071A38`، آبی `#2563EB`، آسمانی `#38BDF8`، نعنایی `#10B981`، زمینهٔ کارت `#F1F7FF`، خط `#D8E5F7`.

## قاب ۷ و ۸ با اسکرین‌شات واقعی

دو قاب آخر تبلیغ نیستند: تصویر واقعی از نصب افزونه روی وردپرس.

- `img/panel-top.webp` برش بالای داشبورد از `../infographic/img/dashboard-dark.webp` است (۱۷۷۶×۹۰۰).
- `08-form.webp` از `../infographic/img/00-card.webp` استفاده می‌کند؛ همان فرم ورود بدون دست‌کاری.
- هیچ اسکرین‌شات بزرگ‌نمایی یا برش‌خورده‌ای که تکه‌ای از رابط را ببرد در مجموعه نیست.

## بازتولید

```bash
# پیش‌نمایش: ریشهٔ مخزن را روی 0.0.0.0:8124 سرو کن
node export.mjs          # raw/*.png در 1600×1800
python3 - <<'PY'         # تبدیل به WebP
from PIL import Image; import glob, os
for f in sorted(glob.glob('raw/*.png')):
    Image.open(f).convert('RGB').save(f.replace('raw/','').replace('.png','.webp'), 'WEBP', quality=90, method=6)
PY
rm -rf raw
node qc.mjs              # کنترل سرریز، برخورد با نوار پایین و هم‌پوشانی بلوک‌ها
```

`qc.mjs` باید `CLEAN` بدهد؛ اگر نداد، مختصات قاب مشکل دارد نه اینکه خطا را نادیده بگیریم.

## نکته‌های محتوایی

- عددهای داخل تصویرها از پیش‌فرض‌های واقعی افزونه آمده‌اند: طول کد ۵، اعتبار ۱۲۰ ثانیه، فاصلهٔ ارسال ۶۰ ثانیه، سقف ۵ در ساعت برای هر شماره و ۱۵ برای هر آی‌پی، مهلت درگاه ۵ ثانیه.
- آدرس بازگشت SSO همان مسیری است که افزونه می‌سازد: `/ashna-sso/callback/google/` و `/ashna-sso/callback/telegram/`.
- نام‌ها و شماره‌ها نمونه‌اند و ماسک شده‌اند؛ هیچ دادهٔ واقعی کاربر در تصویرها نیست.
