## منطق طراحی

هر قاب یک استعارهٔ بصری جدا دارد تا هشت تصویر کنار هم یک قالب تکراری نشوند. سه چیز در همه مشترک است: نشان سپر بالا-راست، خط گرادیانی امضا زیر توضیح، و نوار پایین «آشنا · افزونهٔ وردپرس» با شمارندهٔ قاب. قاب‌های ۰۱–۰۳ روشن‌اند، ۰۴ و ۰۵ سینمایی و تیره، ۰۶ روشن و کنترلی، و ۰۷ و ۰۸ تیره‌اند چون تصویر واقعی محصول‌اند.

## تصویر واقعی، بدون بازسازی

- `img/panel-full.webp` برش کامل داشبورد واقعی (۱۷۷۶×۱۵۴۸) از `../infographic/img/dashboard-dark.webp` است؛ همان‌طور که در پیشخوان دیده می‌شود.
- قاب ۰۶ از `../infographic/img/appearance.webp` استفاده می‌کند و قاب ۰۸ از `../infographic/img/00-card.webp`.
- هیچ اسکرین‌شاتی بازطراحی، بزرگ‌نمایی یا روتوش نشده است؛ فقط قاب، سایه و سطح مایل روی آن نشسته.

## بازتولید

```bash
# پیش‌نمایش باید روی 0.0.0.0:8124 سرو شود
node qc.mjs      # سرریز، برخورد با نوار پایین، هم‌پوشانی عنوان — باید CLEAN بدهد
node export.mjs  # raw/*.png در 1600×1800
python3 - <<'PY'
from PIL import Image; import glob, os
for f in sorted(glob.glob('raw/*.png')):
    Image.open(f).convert('RGB').save(f.replace('raw/','').replace('.png','.webp'), 'WEBP', quality=90, method=6)
PY
rm -rf raw
```

## نکته‌های فنی

- کل بوم یک `<section class="slide">` با `width:800px;height:900px` است؛ خروجی با `deviceScaleFactor: 2` رندر می‌شود.
- لایه‌های نور که از کادر بیرون می‌زنند کلاس `bleed` دارند تا کنترل چیدمان آن‌ها را سرریز حساب نکند.
- فونت‌ها از `assets/fonts/` بارگذاری می‌شوند: Vazirmatn Variable برای متن و Estedad 900 برای تیترها؛ `document.fonts.ready` قبل از عکس‌برداری منتظر می‌ماند.
- پس‌زمینهٔ تیره `#05122B → #0A2350 → #040F1F` است و همان آبی برند در گرادیان تیترها استفاده می‌شود.
- کمترین اندازهٔ متن در کل مجموعه ۷.۲ پیکسل است و هر قاب با چهار ربع ۸۰۰×۹۰۰ بازبینی شده.
