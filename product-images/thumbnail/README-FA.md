# آیکون محصول آشنا — راهنمای ویرایش و خروجی

ابعاد: **۳۲۰×۳۲۰** (نسبت ۱:۱)، مطابق استاندارد آیکون راست‌چین
فرمت‌ها: PNG (۶۴ کیلوبایت) و JPG (۲۲ کیلوبایت) — هر دو RGB و بدون شفافیت

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | آیکون قابل ویرایش، همه‌چیز inline |
| `../ashna-icon-320.png` | خروجی نهایی PNG |
| `../ashna-icon-320.jpg` | خروجی نهایی JPG |
| `render.mjs` | خروجی PNG در مقیاس ۴ (مستر ۱۲۸۰) |
| `shot.mjs` | اسکرین‌شات سریع یک‌باره |

## خروجی گرفتن

```sh
# سرور پیش‌نمایش از ریشهٔ مخزن
python3 -m http.server 8124 --bind 0.0.0.0 --directory .

cd product-images/thumbnail
LD_LIBRARY_PATH=/tmp/alx/lib node render.mjs 4 /tmp/icon-4x.png

# کوچک‌کردن به ۳۲۰ و ذخیرهٔ نهایی
python3 -c "from PIL import Image; im=Image.open('/tmp/icon-4x.png').convert('RGB'); im.resize((320,320), Image.LANCZOS).save('../ashna-icon-320.png', optimize=True)"
```

## ساختار طرح

- **نشان:** سپر آشنا از `../infographic/img/ashna-icon.svg` که با `mask` به پنج لایه تبدیل شده: هاله، سایه، بدنهٔ گرادیانی، برق سطح و ریم‌لایت.
- **نام:** «آشنا» با فونت Estedad 900، سایهٔ دوطبقه و خط نور آبی زیر آن.
- **پس‌زمینه:** سرمه‌ای آشنا با هالهٔ مرکزی، شبکهٔ نقطه‌ای محو و نور گوشه.
- **حاشیهٔ امن:** نشان و نام داخل ۱۰٪ مرکزی ماندند تا در برش‌های مربعی و دایره‌ای آسیب نبینند.

## قواعد ثابت

- هیچ تصویر آماده، استوک یا تولیدشده با هوش مصنوعی استفاده نشده؛ همه‌چیز SVG و CSS است.
- روی آیکون قیمت، تخفیف، لوگوی برند دیگر یا متن طولانی نیست.
- خوانایی در ۹۶ پیکسل هم بررسی شده (نام هنوز خواناست).
