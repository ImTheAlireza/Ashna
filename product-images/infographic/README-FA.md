# اینفوگرافیک تصویری آشنا — راهنمای ویرایش

نسخهٔ کم‌متن اینفوگرافیک با آیکون‌های بزرگ و چند بخش کوتاه طراحی شده است. فایل HTML و
هر دو خروجی عکس در این پوشه قرار دارند.

| فایل | کاربرد |
|---|---|
| `index.html` | طرح قابل ویرایش؛ عرض ثابت ۱۰۰۰ پیکسل و ارتفاع آزاد |
| `ashna-infographic.jpg` | تصویر استاندارد ۱۰۰۰ × ۳۱۱۱ پیکسل؛ مناسب آپلود |
| `ashna-infographic-2x.jpg` | تصویر ۲۰۰۰ × ۶۲۲۲ پیکسل؛ مناسب نمایش با وضوح بیشتر |
| `img/visual-login.webp` و `img/visual-security.webp` | تصویرسازی‌های سه‌بعدی تزئینی |
| `img/ashna-logo-white.svg` | نشان آشنا |
| `export.mjs` و `stitch.py` | رندر و ساخت عکس پس از ویرایش طرح |
| `img/*.webp` دیگر و `shoot-clean.mjs` | تصاویر واقعی پنل و اسکریپت ثبت آن‌ها از نسخهٔ قبلی طرح |

## ساختار طرح

۱. ورود با یک کد و سه قدم کوتاه؛
۲. چهار گروه روش ورود: پیامک و بله، ایمیل، گوگل و تلگرام، و Passkey؛
۳. شش درگاه پیامکی و سه پشتیبان؛
۴. چهار ویژگی امنیتی؛
۵. سازگاری با ووکامرس، دکان و المنتور؛
۶. چهار قالب و پیش‌نمایش زنده.

دو تصویر سه‌بعدی با هوش مصنوعی ساخته شده‌اند و نمایش واقعی پنل افزونه نیستند. آیکون‌های
خطی به‌صورت SVG داخل HTML هستند؛ نشان‌های گوگل، تلگرام، ووکامرس و المنتور از پوشهٔ
`ashna-landing/assets/images/brands/` بارگذاری می‌شوند. فونت‌ها از `assets/fonts/` هستند.

## ویرایش

متن‌ها و چیدمان داخل `index.html` قرار دارند. رنگ‌های اصلی در ابتدای بخش CSS تعریف شده‌اند.
برای حفظ خوانایی، متن‌های جدید را کوتاه نگه دارید. ابعاد طرح را مرورگر به‌صورت خودکار تعیین
می‌کند؛ پس از تغییر متن حتماً هر دو تصویر را دوباره بسازید.

## خروجی تصویر

از ریشهٔ مخزن، یک‌بار وابستگی‌های رندر را نصب کنید (Pillow را در محیط پایتون دلخواه نصب کنید):

```sh
npm install --prefix .cache/browser --no-save --no-package-lock @sparticuz/chromium@141.0.0 playwright-core@1.57.0
python3 -m pip install Pillow
```

روی لینوکس، کتابخانه‌های سیستمی Chromium مانند `libnss3` و `libnspr4` نیز باید نصب باشند.
سپس فایل محلی را رندر کنید؛ برش‌ها در پوشهٔ موقت سیستم ذخیره می‌شوند:

```sh
node product-images/infographic/export.mjs
python3 product-images/infographic/stitch.py 90
python3 product-images/infographic/stitch.py 92 --width 2000 --output product-images/infographic/ashna-infographic-2x.jpg
```

اگر خواستید صفحه را از سرور محلی رندر کنید، URL صفحه را به‌عنوان آرگومان اول `export.mjs`
بدهید. هر دو خروجی کنونی زیر یک مگابایت هستند؛ ابعاد و حجم پس از ویرایش ممکن است تغییر کنند.
