# اینفوگرافیک آشنا — راهنمای ویرایش

این پوشه هم صفحهٔ قابل ویرایش است، هم خروجی نهایی.

| فایل | چیز |
|---|---|
| `index.html` | خود اینفوگرافیک؛ عرض ثابت ۱۰۰۰ پیکسل، ارتفاع آزاد، همه‌چیز داخل یک فایل |
| `img/*.webp` | اسکرین‌شات‌های واقعی پنل و فرم آشنا (۲×، با همان نامی که در HTML صدا زده می‌شوند) |
| `ashna-infographic.jpg` | خروجی استاندارد: ۱۰۰۰ × ۶۵۲۹ پیکسل، حدود ۷۶۷ کیلوبایت؛ مناسب آپلود |
| `ashna-infographic-2x.jpg` | خروجی با وضوح دوبرابر: ۲۰۰۰ × ۱۳۰۵۸ پیکسل، حدود ۲٫۱ مگابایت؛ مناسب بزرگ‌نمایی |
| `shoot-clean.mjs` | اسکریپت گرفتن اسکرین‌شات‌ها از پنل واقعی (۲×، بدون نوار وردپرس و بدون نوار چسبان پنل) |
| `export.mjs` | رندر برش‌های ۲× از فایل HTML محلی، بدون نیاز به سرور |
| `stitch.py` | چسباندن برش‌ها و ساختن JPEG استاندارد یا دوبرابر |

## ساختار طرح

تم آبی برند (`#2563EB`)، هم‌رنگ خود پنل آشنا. هر بخش ساختار خودش را دارد و تکرار نمی‌شود:

| بخش | ساختار |
|---|---|
| هدر | باند تیرهٔ سرمه‌ای با گرید و هاله؛ کارت ورود واقعی با دو کارت شناور |
| سه‌قدم | کارت سفید روی لبهٔ هدر، با خط‌چین بین مراحل |
| ۰۱ ورود و ثبت‌نام | دو ستون روشن، شمارهٔ درشت محو در پس‌زمینه، سه بند تیک‌دار |
| ۰۲ گوگل و تلگرام | باند تیره؛ دو کارت برند کنار هم + اسکرین‌شات کارت گوگل |
| ۰۳ پیامک | زمینهٔ نقطه‌چین؛ نوار «اصلی → سه پشتیبان»، تراشه‌ها و کارت‌های خوانای درگاه |
| ۰۴ امنیت | گرادیان آبی روشن؛ سپر، فهرست شماره‌دار و کارت‌های خوانای سقف پیش‌فرض |
| ۰۵ فروشگاه | دو ستون روشن؛ چهار کارت یکپارچگی کنار متن |
| ۰۶ پنل | باند تیره؛ اسکرین‌شات طراح ظاهر + چهار سواچ قالب |
| فهرست | دو ستون کارتی با عنوان گروه و آیتم‌های درشت‌تر |
| فوتر | باند تیره، نسخه‌ها و برند پارسنا |

همهٔ آیکون‌ها SVG دست‌سازند؛ هیچ تصویر استوک یا هوش مصنوعی در طرح نیست. کارت‌های درگاه
و سقف‌های پیش‌فرض برای خوانایی بیشتر بر اساس تنظیمات پنل با HTML بازچینی شده‌اند؛
بقیهٔ نماهای پنل و فرم، اسکرین‌شات واقعی‌اند.

## ویرایش متن

متن‌ها مستقیم داخل `index.html` هستند؛ عنوان هر بخش و بندهایش همان‌جا عوض می‌شود.
رنگ‌ها در `:root` با متغیرهای `--blue`، `--navy`، `--sky`، `--mint` و `--amber` تنظیم شده‌اند.

## عوض کردن یک تصویر

فایل جدید را با همان نام در `img/` بگذار. چیدمان به‌هم نمی‌ریزد چون ارتفاع خودکار است.
اندازهٔ پیشنهادی: عرض ۱۶۰۰ پیکسل (دو برابر نمایش نهایی) تا رتینا هم تمیز باشد.

هر اسکرین‌شات با `element.screenshot()` گرفته شده، پس لبه‌هایش دقیقاً روی خود کارت است و هیچ
متن یا منوی بریده‌ای ندارد. اگر جایی کارت بلندتر از قاب شد، به‌جای بریدن، همان بخش را دوباره
با اسکریپت بگیر. یک محو ۶٪ پایین قاب (`mask-image` روی `.shot img`) هست که اگر لبهٔ کارت
کمی بریده شد، دیده نشود.

## گرفتن اسکرین‌شات تازه

یک وردپرس با افزونهٔ فعال لازم است (نسخهٔ بدون لایسنس کافی است). سپس:

```
node shoot-clean.mjs http://127.0.0.1:8881
```

اسکریپت لاگین می‌کند، نوار وردپرس و نوار چسبان پنل را پنهان می‌کند و از هر تب فقط همان
کارت لازم را می‌گیرد: فرم ورود، روش ورود، گوگل و تلگرام، درگاه‌ها، سقف‌ها، ووکامرس و طراح ظاهر.
خروجی PNG در `/tmp/caps3` است؛ بعد با یک اسکریپت کوتاه به WebP تبدیل و در `img/` جای‌گذاری می‌شود.

## گرفتن خروجی تصویر

از ریشهٔ مخزن، یک‌بار وابستگی‌های رندر را نصب کنید (Pillow را در محیط پایتون دلخواه نصب کنید):

```sh
npm install --prefix .cache/browser --no-save --no-package-lock @sparticuz/chromium@141.0.0 playwright-core@1.57.0
python3 -m pip install Pillow
```

روی لینوکس، کتابخانه‌های سیستمی Chromium مانند `libnss3` و `libnspr4` نیز باید نصب باشند.
سپس فایل محلی را رندر کنید؛ برش‌ها در پوشهٔ موقت سیستم ذخیره می‌شوند:

```sh
node product-images/infographic/export.mjs
python3 product-images/infographic/stitch.py 90
python3 product-images/infographic/stitch.py 92 --width 2000 --output product-images/infographic/ashna-infographic-2x.jpg
```

اگر خواستید صفحه را از سرور محلی رندر کنید، URL صفحه را به‌عنوان آرگومان اول `export.mjs`
بدهید. خروجی استاندارد **۱۰۰۰ × ۶۵۲۹ پیکسل، حدود ۷۶۷ کیلوبایت** و زیر یک مگابایت است؛
نسخهٔ دوبرابر برای حفظ وضوح هنگام بزرگ‌نمایی جداگانه ذخیره می‌شود.
