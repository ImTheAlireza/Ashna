# اینفوگرافیک آشنا — راهنمای ویرایش

این پوشه هم صفحهٔ قابل ویرایش است، هم خروجی نهایی.

| فایل | چیز |
|---|---|
| `index.html` | خود اینفوگرافیک؛ عرض ثابت ۱۰۰۰ پیکسل، ارتفاع آزاد، همه‌چیز داخل یک فایل |
| `img/*.webp` | اسکرین‌شات‌های واقعی پنل آشنا (با همان نامی که در HTML صدا زده می‌شوند) |
| `ashna-infographic.jpg` | خروجی نهایی: ۱۰۰۰ × ۷۸۴۰ پیکسل، ۹۱۱ کیلوبایت |
| `shoot-clean.mjs` | اسکریپت گرفتن اسکرین‌شات‌ها از پنل واقعی (۲×، بدون نوار وردپرس) |
| `export.mjs` | اسکریپت خروجی تصویر (برش‌های ۱۰۰۰ پیکسلی، تا از سقف ۱۶۳۸۴ پیکسل کروم رد نشود) |
| `stitch.py` | چسباندن همان برش‌ها و ساختن JPEG نهایی |

## ویرایش متن

متن‌ها مستقیم داخل `index.html` هستند؛ عنوان هر بخش و بندهایش همان‌جا عوض می‌شود.
رنگ اصلی هم در `:root` با متغیر `--brand` تنظیم شده است.

## عوض کردن یا بریدن یک تصویر

فایل جدید را با همان نام در `img/` بگذار (مثلاً `img/auth.webp`). چیدمان به‌هم نمی‌ریزد چون ارتفاع خودکار است.
اندازهٔ پیشنهادی: عرض حدود ۱۷۰۰ تا ۲۰۰۰ پیکسل، دو برابر نمایش نهایی، تا روی نمایشگر معمولی و رتینا تمیز باشد.

اگر پایین تصویر فضای خالی یا محتوای تکراری مانده، لازم نیست دوباره از پنل عکس بگیری؛ همان فایل را تا ارتفاع محتوای مفید
ببر (مثلاً با Pillow) تا اینفوگرافیک بی‌دلیل بلند نشود. تصویر `img/appearance.webp` عمداً تا انتهای پیش‌نمایش تیره بریده
شده و `figure.plain` هم ماسک محو سفید ندارد، چون آن ماسک روی زمینهٔ تیره لکهٔ شیری می‌انداخت.

## گرفتن خروجی تصویر

۱. صفحه را در مرورگر باز کن (یا با `python3 -m http.server` سرو کن).
۲. `node export.mjs` — برش‌های ۱۰۰۰ پیکسلی را در `/tmp/slices` می‌سازد.
۳. `python3 stitch.py` — آن‌ها را عمودی می‌چسباند و `ashna-infographic.jpg` را می‌نویسد.

خروجی فعلی: **۱۰۰۰ × ۷۸۴۰ پیکسل، ۹۱۱ کیلوبایت** — زیر سقف یک مگابایتِ راست‌چین.
