# لندینگ آشنا — راهنمای استقرار و ویرایش

این پوشه، لندینگ معرفی محصول **آشنا ۳.۱.۳** است؛ کاملاً اختصاصی و بدون قالب آماده.
HTML، CSS و JavaScript دست‌نویس، فونت و لوگو محلی، بدون CDN و بدون فریم‌ورک.
همهٔ دارایی‌ها داخل همین پوشه‌اند و مسیرها نسبی هستند.

## اجرای محلی

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

سپس `http://localhost:8080` را باز کنید. برای آپلود روی هاست، فقط محتویات همین پوشه را
در پوشهٔ مقصد (مثلاً `public_html/ashna/`) کپی کنید؛ به PHP یا وردپرس نیاز ندارد.

## ساختار

```
index.html                  صفحهٔ اصلی (RTL، فارسی)
assets/css/style.css        طراحی و چیدمان؛ توکن‌های رنگ و فونت در :root
assets/css/admin-panel.css       کپی بدون تغییر assets/css/admin.css افزونه (استایل تب پیشخوان)
assets/css/admin-panel-inline.css  کپی استایل درون‌خطی settings-page.php (حالت تاریک، آیکون‌ها)
assets/js/main.js           تعامل‌ها + پیکربندی لینک خرید و دمو
assets/fonts/               وزیرمتن (متن) و استعداد (تیتر) — محلی، OFL
assets/images/              لوگو، آیکون و تصویر شبکه‌های اجتماعی
assets/images/dashboard-preview.jpg  تصویر ۱۵۲۰×۸۷۰ از همان تب پیشخوان برای نمایشگرهای باریک
.htaccess                   فشرده‌سازی، کش، هدرهای امنیتی
robots.txt                  ایندکس مجاز فقط برای همین صفحه
```

## سه خطی که قبل از انتشار باید ویرایش شود

در `assets/js/main.js`، ابتدای فایل:

```js
var ASHNA_CONFIG = {
  purchaseUrl: "https://www.rtl-theme.com/…", // لینک نهایی محصول در راست‌چین
  demoUrl: "",                               // مثل "https://demo.parsena.ir/"
  supportUrl: ""                             // لینک پرسش/پشتیبانی (اختیاری)
};
```

- **purchaseUrl** باید به صفحهٔ نهایی محصول در راست‌چین برود. تا وقتی منتشر نشده، مقدار
  موقت جست‌وجوی راست‌چین گذاشته شده است. همهٔ دکمه‌های خرید با `data-buy` همین لینک را می‌گیرند
  و در تب جدید باز می‌شوند.
- **demoUrl** را بعد از راه‌اندازی وردپرس دمو روی `demo.parsena.ir` بگذارید. تا آن زمان،
  دکمه‌های دموی واقعی به دموی ورود بالای همین صفحه اشاره می‌کنند و پیام «در حال آماده‌سازی» نشان می‌دهند.
- اگر **supportUrl** پر شود، بهتر است لینک «پرسش در راست‌چین» به همان اشاره کند.

شمارهٔ نسخه، اعداد نوار اثبات و لینک‌های کنونیکال/OG در بالای `index.html` قرار دارند.

## چه چیزی در این صفحه واقعی است و چه چیزی شبیه‌سازی؟

| بخش | وضعیت |
|---|---|
| نسخهٔ نمایشی فرم ورود | همان جریان لندینگ اصلی: ارسال کد، گوشی با نوتیفیکیشن پیامک، اسکن Passkey (چهره/اثر انگشت) و کارت ورود موفق. کد تایید تصادفی است و فقط همان کد قبول می‌شود؛ هیچ درخواستی ارسال نمی‌شود. |
| تب پیشخوان افزونه | همان تب پیشخوان واقعی: مارک‌آپ و CSS از خود افزونه (`assets/css/admin-panel.css` کپی `assets/css/admin.css` و `admin-panel-inline.css` کپی استایل درون‌خطی `settings-page.php`). تنها داده‌ها نمایشی‌اند؛ حالت تاریک و کپی شورت‌کد واقعی کار می‌کنند. |
| نمای باریک پیشخوان | زیر ۱۲۸۰ پیکسل، همان پنل به‌صورت یک تصویر ۱۵۲۰×۸۷۰ نشان داده می‌شود تا چیدمان دسکتاپ فشرده و ناخوانا نشود. |
| اعداد نوار اثبات | از گزارش امنیت (۵۸۹ بررسی خودکار) و گزارش تست بار (۲٬۲۲۶ جریان ورود)؛ نسخهٔ ۳.۱.۳. |
| لینک خرید | مقصد قابل تنظیم؛ تا انتشار صفحهٔ راست‌چین، جست‌وجوی محصول. |

> **قاعدهٔ انتشار:** هیچ ویژگی «به‌زودی» در این صفحه نیست. اگر قابلیتی را از افزونه حذف
> کردید، کارت مربوط به آن را هم حذف کنید. اگر تصویر واقعی پنل را جایگزین بازسازی کردید،
> برچسب «نمایشی» را بردارید.

## تب پیشخوان از کجا آمده و چطور به‌روز می‌شود

بخش `#admin` ماکت دست‌ساز نیست. مارک‌آپ از `includes/admin/views/partials/tab-dashboard.php`
گرفته شده و استایل‌ها دو کپی بدون تغییر از خود افزونه‌اند:

- `assets/css/admin-panel.css` = `assets/css/admin.css` (کل استایل پنل)
- `assets/css/admin-panel-inline.css` = بلوک `<style>` داخل `settings-page.php` (حالت تاریک، آیکون ماه/خورشید، توست)

پنل در عرض طراحی ۱۵۲۰ پیکسل چیده می‌شود (همان عرضی که برای آن نوشته شده) و با
`zoom` روی عرض کادر صفحه کوچک می‌شود؛ این کار فقط در جاوااسکریپت `main.js` انجام می‌شود.
زیر ۱۲۸۰ پیکسل، جای پنل زنده یک تصویر ثابت از همان تب می‌آید
(`assets/images/dashboard-preview.jpg`). اگر افزونه به‌روزرسانی شد، این دو فایل CSS و
تصویر را دوباره از نسخهٔ جدید بگیرید؛ مقادیر نمایشی داخل `index.html` نوشته شده‌اند.

اگر بعداً خواستید اسکرین‌شات واقعی از نصب وردپرس بگذارید، فقط `<img>` را با فایل خودتان
عوض کنید و در متن بخش بنویسید که از نسخهٔ نصب‌شده گرفته شده است. تصویر محصول نباید شمارهٔ
واقعی کاربر، کلید API یا اطلاعات لایسنس داشته باشد.

## دسترس‌پذیری و مرورگرها

- جهت `rtl`، اعداد فارسی در متن، ورودی شماره و کد به‌صورت `LTR`.
- همهٔ کنترل‌ها با کیبورد قابل استفاده‌اند؛ کادر پیشخوان با Tab فوکوس می‌شود و با کلیدهای جهت‌دار اسکرول می‌شود.
- `prefers-reduced-motion` رعایت می‌شود؛ محتوا بدون JavaScript هم خوانده می‌شود.
- تست‌شده روی Chromium و Firefox (نسخه‌های دسکتاپ و شبیه‌ساز موبایل ۳۹۰×۸۴۴).
- تارگت اندازه: LCP زیر ۲٫۵ ثانیه روی اتصال پهن‌باند؛ JS اولیه زیر ۳۰KB.

## چه چیزی را در این پوشه نگذارید

- فایل ZIP افزونه یا لایسنس (فقط لینک خرید).
- شمارهٔ واقعی کاربران، لاگ، کلید API یا توکن.
- اسکرین‌شات با برند قدیمی یا فایل لوگوی نسخهٔ قبل.
- اسکریپت تحلیلی که شمارهٔ موبایل را جمع می‌کند؛ اگر سنجه می‌خواهید، از Matomo خودمیزبان
  با ناشناس‌سازی IP استفاده کنید.

## استقرار پیشنهادی

| مسیر | محتوا |
|---|---|
| `parsena.ir/ashna/` | همین پوشه (استاتیک) |
| `demo.parsena.ir/` | وردپرس دمو با آشنا، فقط درگاه Sandbox و `show_debug_code_in_toast` روشن |

لینک پیش‌نمایش راست‌چین باید به `https://demo.parsena.ir/` برود و لینک Plugin URI افزونه به
`https://parsena.ir/ashna/`. ساب‌دامین دمو باید `noindex` باشد.

## بستهٔ تحویل

`deliverables/ashna-landing.zip` نسخهٔ قابل آپلود همین پوشه است. برای بازسازی بعد از هر تغییر:

```sh
python3 scripts/package-landing.py
```

## چه چیزی هنوز واقعی نیست (برای ارسال به راست‌چین)

۱. **فرم هیرو** یک نمایش تعاملی از رابط است، نه فرم متصل به وردپرس. برای پذیرش کامل بند ۹، یا دموی
   `demo.parsena.ir` را وصل کنید و `demoUrl` را پر کنید، یا همان جملهٔ «نسخهٔ نمایشی رابط» را
   که الان زیر کارت ورود هست نگه دارید.
۲. **تب پیشخوان** با مارک‌آپ و CSS خود افزونه ساخته شده، اما داده‌های داخل آن نمایشی‌اند و از
   نصب وردپرس خوانده نمی‌شوند. دو صفحهٔ شبیه‌ساز قبلی (قطعی درگاه و ماشین‌حساب پیامک‌بمب) حذف شدند؛
   همان واقعیت‌ها الان داخل همین پنل دیده می‌شوند: درگاه‌های پشتیبان، سقف‌ها و لاگ ارسال.
۳. **لینک خرید** فعلاً جست‌وجوی راست‌چین است تا صفحهٔ محصول منتشر شود.
۴. **گالری محصول** و **PDF راهنما** با برند قبلی از مخزن حذف شدند و باید از نو ساخته شوند.
