# نشان‌های برند در لندینگ آشنا

همهٔ فایل‌ها فقط برای معرفی «سازگاری» آمده‌اند. نمایش یک نشان به معنی تأیید، همکاری یا وابستگی رسمی نیست و حق هر نشان مال صاحبش است.

| فایل | برند | منبع |
|---|---|---|
| `wordpress.svg` | WordPress | simple-icons (CC0) |
| `woocommerce.svg` | WooCommerce (قفل واژه) | simple-icons (CC0) |
| `woo.svg` | WooCommerce (بالون) | simple-icons (CC0) |
| `elementor.svg` | Elementor | simple-icons (CC0) |
| `google.svg` | Google «G» چهاررنگ | نشان استاندارد گوگل برای ورود |
| `telegram.svg` | Telegram | simple-icons (CC0) |
| `ultimate-member.png` | Ultimate Member | آیکون رسمی افزونه در مخزن `ultimatemember/ultimatemember` |
| `paid-memberships-pro.png` | Paid Memberships Pro | آیکون رسمی در مخزن `strangerstudios/paid-memberships-pro` |
| `memberpress-mark.svg` | MemberPress (نشان «m») | برش نشان از فایل قفل‌واژهٔ رسمی |
| `smsir.png` | SMS.ir | صفحهٔ برند (Brandfetch)، پیش‌تر در مخزن برای گالری |

| `bale.png` | بله | از دارایی‌های خود افزونه (`assets/images/bale-logo.png`) |

«دکان» در کارت یکپارچگی‌ها با قفل‌واژهٔ متنی (`dokan`) نشان داده شده است، چون فایل نشان رسمی و قابل‌تأییدی از آن در دسترس نبود و نشان ساختگی ساخته نشد.

## دیدن یک نشان

اگر صاحب برندی نخواهد نشانش اینجا باشد، همان فایل حذف و جای آن نام متنی برند می‌آید؛ بقیهٔ صفحه به آن وابسته نیست.
